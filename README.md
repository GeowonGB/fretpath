# FretPath

FretPath is an interactive, browser-based guitar learning platform designed to take absolute beginners through to intermediate mastery. 

## Features

- **Interactive Roadmap**: A visual, stage-by-stage learning path.
- **Audio Recognition**: Real-time pitch detection to ensure you're playing the right notes and chords (via microphone).
- **Guided AI Tutor**: A holographic 'orb' that speaks instructions, highlighting interactive guitar diagrams.
- **Practice Modules**: Built-in quizzes, tuners, and metronomes.
- **Persistent Progress**: Your journey and settings are automatically saved locally.

## Tech Stack

- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **State Management**: Zustand v5
- **Routing**: React Router v7
- **Graphics**: Three.js (WebGL Guide Orb)
- **Icons**: Lucide React
